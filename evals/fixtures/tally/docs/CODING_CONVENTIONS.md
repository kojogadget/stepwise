# Tally — Coding Conventions

## 1. Vocabulary

| Concept | Use | Not |
| --- | --- | --- |
| Number of words | `word_count` | `total`, `n`, `wc` |
| A failed read | `ReadFailure` | `error`, `exception` |

## 2. Naming

- Functions are `snake_case` verbs: `count_words`, `read_text`.
- Tests are named `test_<behavior>`.
